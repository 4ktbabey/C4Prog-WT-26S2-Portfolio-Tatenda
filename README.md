# Web Technologies Portfolio

## Phase 3 – Component Identification

The following ScreenCraft components have been identified for the portfolio dashboard:

1. Header with Navigation on Right: Displays the website title and navigation links.
2. Navigation: Provides links to Home, Phase 1, Phase 2 and Phase 3.
3. Hero: Introduces the portfolio with a welcome heading and description.
4. Vertical Cards: Displays information about each portfolio phase.
5. Buttons: Allows users to open each portfolio phase.
6. Simple Footer: Displays copyright information at the bottom of the website.

### Layout and Styling

Tailwind CSS will be used to organise the dashboard, style the components and make the website responsive.

Some ScreenCraft categories did not have suitable examples, so custom HTML and Tailwind CSS will be used where needed.
